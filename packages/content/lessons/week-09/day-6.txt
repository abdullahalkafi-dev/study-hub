@section math | 2 · Part A: Integration techniques (14 marks, about 55 min) | no calculator

LVL: Part A | Questions 1 to 13
P: (1 mark) Find ∫ x e^(2x) dx. => u = x, v = e^(2x) ÷ 2: **x e^(2x) ÷ 2 − e^(2x) ÷ 4 + C**.
P: (1 mark) Evaluate ∫₁ᵉ x ln x dx. => [(x²/2) ln x − x²/4] = (e²/2 − e²/4) − (0 − 1/4) = **(e² + 1) ÷ 4 ≈ 2.10**.
P: (1 mark) Evaluate ∫₀^π sin² x dx. => **π/2**.
P: (1 mark) Evaluate ∫₀^(π/2) cos³ x dx. => cos³ x = (1 − sin² x) cos x. With u = sin x from 0 to 1: ∫ (1 − u²) du = 1 − 1/3 = **2/3**.
P: (1 mark) Find ∫ 3 ÷ ((x − 1)(x + 2)) dx. => 3 ÷ ((x − 1)(x + 2)) = 1 ÷ (x − 1) − 1 ÷ (x + 2). So **ln abs((x − 1) ÷ (x + 2)) + C**.
P: (1 mark) Evaluate ∫₀¹ 1 ÷ ((x + 1)(x + 3)) dx. => 1 ÷ ((x + 1)(x + 3)) = ½ [1 ÷ (x + 1) − 1 ÷ (x + 3)]. [½ ln((x + 1) ÷ (x + 3))] from 0 to 1 = ½ [ln(1/2) − ln(1/3)] = **½ ln(3/2) ≈ 0.203**.
P: (1 mark) Evaluate ∫₁^∞ 2 ÷ x³ dx. => [−1 ÷ x²] from 1 to ∞ = 0 − (−1) = **1**.
P: (1 mark) Evaluate ∫₀^∞ x e^(−2x) dx. => By parts: [−x e^(−2x) ÷ 2 − e^(−2x) ÷ 4] from 0 to ∞ = 0 − (−1/4) = **1/4**.
P: (1 mark) Decide whether ∫₁^∞ x^(−3/2) dx and ∫₁^∞ x^(−1/2) dx converge, and give the value if so. => The first has p = 3/2 > 1, so it converges to 1 ÷ (3/2 − 1) = **2**. The second has p = 1/2 ≤ 1, so it **diverges**.
P: (1 mark) Estimate ∫₀² x³ dx with the trapezoid rule and with Simpson's rule, each with n = 2. Which is exact? => h = 1, values 0, 1, 8. Trapezoid: ½ × [0 + 2 + 8] = **5**. Simpson: (1 ÷ 3) × [0 + 4 + 8] = **4**, **exact** (the true value is 4).
P: (1 mark) Estimate ∫₀^π sin x dx by Simpson's rule with n = 2. => h = π/2, values 0, 1, 0. S = (π/6) × [0 + 4 + 0] = **2π/3 ≈ 2.094**.
P: (1 mark) A uniform chain of mass 8 kg and length 4 m hangs over an edge. Find the work to pull it all up. => λ = 2 kg/m. W = ∫₀⁴ λ g y dy = 2 × 9.8 × 16/2 = **156.8 J**.
P: (2 marks) Evaluate ∫₀^∞ x² e^(−x) dx and explain why the boundary terms vanish. => By parts with u = x²: [−x² e^(−x)] from 0 to ∞ + 2 ∫₀^∞ x e^(−x) dx. The bracket is 0 at both ends (at ∞ because e^(−x) beats any power of x). The remaining integral is 2 × 1, so the answer is **2** (this is 2!).

@section physics | 3 · Part B: Oscillations (6 marks, about 35 min) | calculator allowed

LVL: Part B | Questions 14 to 19
P: (1 mark) A 0.4 kg mass is on a spring with k = 160 N/m. Find ω and T. => ω = √(160 ÷ 0.4) = √400 = **20 rad/s**. T = 2π ÷ 20 = **0.314 s**.
P: (1 mark) That oscillator has an amplitude of 0.06 m. Find the total energy and the speed at x = 0.03 m. => E = ½ × 160 × 0.0036 = **0.288 J**. v = ω √(A² − x²) = 20 √(0.0036 − 0.0009) = 20 × 0.052 = **1.04 m/s**.
P: (1 mark) Find the period of a simple pendulum of length 0.8 m. => T = 2π √(0.8 ÷ 9.8) = 2π × 0.2857 = **1.80 s**.
P: (1 mark) Find the period of a uniform rod of length 0.9 m pivoted at one end. => T = 2π √(2 L ÷ (3 g)) = 2π √(1.8 ÷ 29.4) = 2π × 0.2474 = **1.55 s**.
P: (1 mark) A damped oscillator has m = 2 kg, k = 200 N/m and c = 8 N·s/m. Find γ, ω_d, and the fraction of the amplitude left after 1 s. => γ = c ÷ (2m) = **2 per second**. ω₀ = 10, so ω_d = √(100 − 4) = **9.80 rad/s**. Fraction = e^(−2) = **0.135**. (c_c = 2√(200 × 2) = 40, so it is underdamped.)
P: (1 mark) A driven oscillator has m = 1 kg, k = 400 N/m, c = 2 N·s/m and F₀ = 10 N. Find the amplitude at resonance and the quality factor Q. => ω₀ = 20 rad/s. A = F₀ ÷ (c ω₀) = 10 ÷ 40 = **0.25 m**. Q = m ω₀ ÷ c = **10**.

### Challenges of the week
LVL: Challenge | The area under a damped wave
P: A damped oscillation has the shape y = e^(−x) sin x for x ≥ 0. Find ∫₀^∞ e^(−x) sin x dx using the cycle trick. Why does the total signed area stay finite even though the wave never stops? => Let I = ∫ e^(−x) sin x dx. By parts (u = sin x): I = −e^(−x) sin x + ∫ e^(−x) cos x dx. By parts again (u = cos x): ∫ e^(−x) cos x dx = −e^(−x) cos x − I. So I = −e^(−x) sin x − e^(−x) cos x − I, giving 2I = −e^(−x) (sin x + cos x) and I = −½ e^(−x) (sin x + cos x). From 0 to ∞: 0 − (−½ (0 + 1)) = **1/2**. The humps shrink geometrically (each is e^(−π) ≈ 4% of the one before it, with alternating signs), so their areas add up to a finite total.

LVL: Challenge | Power absorbed at resonance
P: A driven oscillator has steady displacement x = A cos(ωt − δ). The damping force removes power c v², whose average is ½ c ω² A². Show that the average power absorbed at resonance is F₀² ÷ (2c), independent of m and k, and compute it for F₀ = 10 N and c = 2 N·s/m. => Average of v² = ω² A² × (average of sin²) = ½ ω² A². At resonance A = F₀ ÷ (c ω₀) and ω = ω₀, so P = ½ c ω₀² × F₀² ÷ (c² ω₀²) = **F₀² ÷ (2c)**. For the numbers, P = 100 ÷ 4 = **25 W**. (In a steady state this equals the power the driving force puts in: F₀ ÷ 2 times the velocity amplitude A ω₀ = F₀ ÷ c gives F₀² ÷ (2c) ✓.)
