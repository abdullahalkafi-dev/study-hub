# Taylor and Maclaurin series. Then: standing waves and music
lead: Here is the payoff of the whole week. Any smooth function can be written as a power series built from its derivatives at one point, the Taylor series. This is exactly how your calculator computes sin x, eˣ and ln x: it adds a few terms of a series. In physics, you trap a wave between two fixed ends and get standing waves, the harmonics that make a guitar string, a flute or your own voice produce notes.

BN: সপ্তাহের আসল ফল এখানে। যেকোনো মসৃণ ফাংশনকে একটি বিন্দুর অন্তরকলজ দিয়ে গড়া ঘাত ধারায় লেখা যায়: টেলর ধারা (Taylor series)। ক্যালকুলেটর ঠিক এভাবেই sin x, eˣ, ln x বের করে: ধারার কয়েকটা পদ যোগ করে। পদার্থবিজ্ঞানে তরঙ্গকে দুই স্থির প্রান্তের মধ্যে আটকে পাবে স্থির তরঙ্গ (standing wave), অর্থাৎ হারমোনিক, যা গিটারের তার, বাঁশি বা তোমার গলা থেকে সুর তৈরি করে।

@section math | 2 · Math: Taylor series | 55 min

### The idea: match all the derivatives
We want a power series that agrees with f at x = a **in value and in every derivative**. If f(x) = Σ cₙ (x − a)ⁿ, differentiating n times at x = a leaves f⁽ⁿ⁾(a) = n! cₙ. So:

EQ: f(x) = Σ from n = 0 of [f⁽ⁿ⁾(a) ÷ n!] (x − a)ⁿ = f(a) + f′(a)(x − a) + f″(a)(x − a)²/2! + f‴(a)(x − a)³/3! + …

With a = 0 it is called the **Maclaurin series**. The first two terms are exactly the linearisation from Week 7; each further term adds more curvature.

BN: ফাংশনের মান ও প্রতিটি অন্তরকলজ বিন্দুতে মেলাতে চাই। f(x) = Σcₙ(x − a)ⁿ হলে n বার অন্তরকলনে f⁽ⁿ⁾(a) = n!·cₙ। তাই টেলর ধারা: f(a) + f′(a)(x − a) + f″(a)(x − a)²/2! + …। a = 0 হলে ম্যাকলরিন ধারা। প্রথম দুই পদ হলো সপ্তাহ ৭ এর রৈখিক আসন্নকরণ।

### The big five (Maclaurin)
| Function | Series | Valid for |
| eˣ | 1 + x + x²/2! + x³/3! + x⁴/4! + … | all x |
| sin x | x − x³/3! + x⁵/5! − x⁷/7! + … | all x |
| cos x | 1 − x²/2! + x⁴/4! − x⁶/6! + … | all x |
| ln(1 + x) | x − x²/2 + x³/3 − x⁴/4 + … | −1 < x ≤ 1 |
| (1 + x)ᵏ | 1 + k x + k(k − 1) x²/2! + k(k − 1)(k − 2) x³/3! + … | abs(x) < 1 |

EX: Deriving the sine series
1. f = sin x. The derivatives at 0 cycle: sin 0 = 0, cos 0 = 1, −sin 0 = 0, −cos 0 = −1, then repeat.
2. So f⁽ⁿ⁾(0) = 0, 1, 0, −1, 0, 1, 0, −1, … Only odd powers survive, with alternating signs.
3. **sin x = x − x³/6 + x⁵/120 − x⁷/5040 + …** Cosine, from differentiating, has only even powers.
4. Check: d/dx of the sine series is 1 − x²/2 + x⁴/24 − … = cos x ✓.
/EX

/EX

### Taylor series about another point
When x is far from 0, expand about a nearby convenient point a.

EX: Around a = 4 and around a = 1
1. f = √x about a = 4: f(4) = 2, f′ = 1 ÷ (2√x) = 1/4, f″ = −1 ÷ (4 x^(3/2)) = −1/32. So **√x ≈ 2 + (x − 4)/4 − (x − 4)²/64**. For x = 4.2: 2 + 0.05 − 0.000625 = **2.049375** (true 2.049390).
2. f = ln x about a = 1: ln x = (x − 1) − (x − 1)²/2 + (x − 1)³/3 − …. For x = 1.2: 0.2 − 0.02 + 0.00267 = **0.18267** (true 0.18232).
/EX

### How big is the error?
If you stop after the term of degree n, the error (the **remainder**) is at most

EQ: abs(Rₙ) ≤ M abs(x − a)ⁿ⁺¹ ÷ (n + 1)!     where M is the largest abs(f⁽ⁿ⁺¹⁾) between a and x

For sine and cosine, M = 1, so the error is tiny whenever x is small and n is moderate.

EX: Error bound
1. sin 1 with terms up to x⁵: 1 − 1/6 + 1/120 = **0.841667**. The bound is 1⁷ ÷ 7! = 0.000198. True error: 0.000196 ✓.
2. How many terms for sin 1 to be right within 10⁻⁶? Need 1 ÷ (n + 1)! < 10⁻⁶, so (n + 1)! > 10⁶, n + 1 = 10, and the terms to x⁷ or x⁹ suffice.
/EX

### Euler's formula (a preview of Phase 3)
Put ix into the series for eˣ and use i² = −1, i³ = −i, i⁴ = 1:

e^(ix) = 1 + ix − x²/2 − i x³/6 + x⁴/24 + i x⁵/120 − … = (1 − x²/2 + x⁴/24 − …) + i (x − x³/6 + x⁵/120 − …).

EQ: e^(ix) = cos x + i sin x     and with x = π:     e^(iπ) + 1 = 0

Real and imaginary parts are exactly the cosine and sine series. This connects exponentials and waves, and it is why complex numbers (Week 12) simplify oscillations so much.

BN: ম্যাকলরিন ধারা: eˣ = Σxⁿ/n!, sin x = x − x³/3! + x⁵/5! − …, cos x = 1 − x²/2! + x⁴/4! − …, ln(1 + x) = x − x²/2 + x³/3 − …। ত্রুটি ≤ M|x − a|ⁿ⁺¹/(n + 1)!। e^(−x²) এর সমাকলন সূত্র ছাড়া হয় না, কিন্তু ধারায় পদে পদে সমাকলন করে যতটা চাও নিখুঁত মান পাওয়া যায়। অয়লারের সূত্র: e^(ix) = cos x + i sin x, তাই e^(iπ) + 1 = 0।

TRAP: Angles must be in **radians** in all these series. The Taylor series of sin x has only **odd** powers, and cos x only **even**: do not mix them. For ln(1 + x) and (1 + x)ᵏ the series works only for abs(x) < 1 (and a few endpoints), so do not use it for ln 5 directly. And a Taylor polynomial is only a good approximation **near a**.

@section physics | 3 · Physics: standing waves and music | 35 min

### Waves trapped between two ends
A wave on a string fixed at both ends reflects (inverted) at each end and the left- and right-moving waves overlap. Add them:

EQ: y = A sin(kx − ωt) + A sin(kx + ωt) = 2A sin(kx) cos(ωt)

This is a **standing wave**: it has a fixed shape sin(kx) whose size oscillates with cos ωt. Points where sin kx = 0 never move (**nodes**), and points where abs(sin kx) = 1 move the most (**antinodes**).

The string is fixed at x = 0 and x = L, so sin(kL) = 0 and kL = nπ, giving k = nπ ÷ L, a **whole number of half wavelengths** fitting on the string:

EQ: λₙ = 2L ÷ n     fₙ = v ÷ λₙ = n v ÷ (2L) = n f₁     (n = 1, 2, 3, …)     f₁ = (1 ÷ (2L)) √(T ÷ μ)

The n = 1 mode is the **fundamental**, and n = 2, 3, … are the **overtones** or **harmonics**: their frequencies are whole-number multiples of f₁. There are n − 1 nodes between the ends.

BN: দুই প্রান্তে আটকানো তারে ডান-বাম তরঙ্গ মিলে y = 2A sin(kx) cos(ωt) হয়: আকৃতি স্থির, আকার দোলে। সরণহীন বিন্দু = নোড (node), সর্বোচ্চ = অ্যান্টিনোড। প্রান্ত স্থির বলে kL = nπ, অর্থাৎ তারে অর্ধতরঙ্গদৈর্ঘ্যের পূর্ণসংখ্যা: λₙ = 2L/n, fₙ = n·v/(2L) = n·f₁। n = 1 মূল সুর (fundamental), বাকিরা হারমোনিক।

EX: A guitar string
1. L = 0.65 m, μ = 5 × 10⁻⁴ kg/m, T = 70 N: v = 374 m/s. The fundamental is f₁ = 374 ÷ (2 × 0.65) = **288 Hz**. The harmonics are 576, 864, 1152 Hz, …
2. **Fretting** shortens the vibrating length. At L = 0.5 m: f₁ = 374 ÷ 1.0 = **374 Hz**. Pressing the string at the midpoint (L = 0.325 m) gives double the frequency: an **octave** higher.
3. **Tuning**: to raise 288 Hz to 293.7 Hz (a D), since f ∝ √T the tension must rise by (293.7 ÷ 288)² − 1 = **4.0%**.
/EX

EX: Where you pluck matters
1. A string plucked at its **midpoint** cannot support modes that have a node there (all even harmonics), so it sounds with odd harmonics only: a hollow tone.
2. Plucked near the **bridge**, many harmonics are excited at once: a bright, twangy tone. This difference of **timbre** is what makes a violin sound different from a flute at the same note. (Phase 3 will show how any shape is a sum of harmonics: Fourier series.)
/EX

### Sound in pipes
Air in a pipe also forms standing waves. The **ends** decide the pattern: an open end is a pressure node (displacement antinode), and a closed end is a pressure antinode (displacement node).

EQ: Open at both ends:  fₙ = n v ÷ (2L)  (n = 1, 2, 3, …)     Closed at one end:  fₙ = n v ÷ (4L)  (n = 1, 3, 5, …, odd only)

EX: Pipes and voices
1. A closed pipe 0.25 m long (v = 343 m/s): f₁ = 343 ÷ 1 = **343 Hz**, and the next harmonics are 1029 and 1715 Hz (odd only). An **open** pipe of the same length has f₁ = **686 Hz**, one octave higher.
2. The human vocal tract is about 0.17 m long, closed at the glottis and open at the lips. f₁ = 343 ÷ 0.68 = **504 Hz**, with further resonances at 1513 and 2521 Hz. These are the **formants** that shape vowels.
3. The lowest note of a large organ pipe, 20 Hz, needs an open pipe of length L = 343 ÷ (2 × 20) = **8.6 m**.
/EX

TRAP: A standing wave is **not** travelling: it carries no net energy along the string. The fundamental has λ = **2L**, not L. For a pipe, check which ends are open: a closed-open pipe has only **odd** harmonics and f₁ = v ÷ (4L), not v ÷ (2L). And fretting changes the length L (not the speed v).
