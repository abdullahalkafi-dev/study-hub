@section math | 2 · Math: what a function is, and the quadratic | 55 min

### A machine with one rule
A **function** is a machine. You feed in a number (the **input**, usually x). The machine applies a fixed rule. Out comes exactly one number (the **output**, usually y).

EQ: f(x) = 2x + 3     input x → multiply by 2 → add 3 → output

We read f(x) as "f of x". f(4) means "put 4 into the machine": f(4) = 2(4) + 3 = 11. The letter f is just the machine's name. You can have g(x), h(t), or v(t) for a velocity that depends on time.

KEY: The defining rule: **each input gives exactly one output.** Two different inputs may give the same output, but one input can never give two.

BN: ফাংশন মানে একটা মেশিন। ইনপুট ঢুকাও, একটা নিয়ম কাজ করে, আউটপুট বের হয়। f(4) মানে মেশিনে ৪ ঢুকিয়ে দেখো কী বের হয়। মূল শর্ত: একটা ইনপুটের জন্য একটাই আউটপুট। দুটো আলাদা ইনপুটের আউটপুট একই হতে পারে, কিন্তু একই ইনপুটের দুটো আউটপুট হতে পারে না।

### Domain and range
- The **domain** is the set of all inputs the machine accepts.
- The **range** is the set of all outputs it can produce.

Some machines break on certain inputs:
- f(x) = 1/x: you cannot divide by zero, so the domain is all x except 0.
- f(x) = √x: you cannot take the square root of a negative number (in real numbers), so the domain is x ≥ 0, and the outputs are also ≥ 0.
- f(x) = x²: any input works, but the output is never negative, so the range is y ≥ 0.

EX: Domain of f(x) = √(x − 3) ÷ (x − 5)
1. The square root needs x − 3 ≥ 0, so x ≥ 3.
2. The denominator cannot be zero, so x ≠ 5.
3. Domain: **x ≥ 3 but x ≠ 5**.
/EX

### The vertical line test
A graph shows a function only if every vertical line crosses it **at most once**. A circle x² + y² = 25 fails: at x = 3 it has both y = 4 and y = −4. So a circle is not a function y(x), but its top half y = √(25 − x²) is.

### Straight lines: y = mx + c
The simplest function. **m** is the slope (rise ÷ run) and **c** is where the line crosses the y-axis.

EX: A line through two points
1. Find the line through (1, 3) and (4, 9).
2. Slope m = (9 − 3) ÷ (4 − 1) = 6 ÷ 3 = 2.
3. Use y = mx + c with a point: 3 = 2(1) + c, so c = 1.
4. The line is **y = 2x + 1**. Check the other point: 2(4) + 1 = 9 ✓.
/EX

### Piecewise functions
Real rules often change by range. A taxi charges 50 taka plus 20 taka per km for the first 5 km, then 15 per km after that.

EQ: f(d) = 50 + 20d  for 0 ≤ d ≤ 5     and     f(d) = 150 + 15(d − 5)  for d > 5

At d = 8: 150 + 15 × 3 = **195 taka**. The two pieces meet at d = 5 (both give 150), so there is no jump in price.

### Quadratic functions
A **quadratic** has the form f(x) = ax² + bx + c with a ≠ 0. Its graph is a **parabola**, a U-shape (if a > 0) or an upside-down U (if a < 0). Parabolas describe thrown balls, bridge cables and satellite dishes.

The key feature is the **vertex**, the turning point. To find it, we use a technique called **completing the square**. It also gives us the quadratic formula, so let's derive it once, carefully.

EX: Complete the square for x² + 6x + 1
1. We want x² + 6x to look like (x + something)². Since (x + 3)² = x² + 6x + 9, we need 9. Take half of 6 (that is 3) and square it.
2. x² + 6x + 1 = (x² + 6x + 9) − 9 + 1 = (x + 3)² − 8.
3. The vertex is at **(−3, −8)**. The smallest value of the function is −8, reached at x = −3.
/EX

BN: বর্গ পূর্ণ করা (completing the square) মানে x² + 6x কে (x + 3)² এর মতো করে সাজানো। কৌশল: x এর সহগের অর্ধেক নাও, তার বর্গ যোগ করো আর বিয়োগও করো। এতে ভার্টেক্স (বক্ররেখার সর্বনিম্ন বা সর্বোচ্চ বিন্দু) সরাসরি পাওয়া যায়: (x + 3)² − 8 থেকে ভার্টেক্স (−3, −8)।

### Deriving the quadratic formula
Take ax² + bx + c = 0 and complete the square in general.

EX: The derivation
1. Divide by a: x² + (b/a)x + c/a = 0.
2. Move the constant: x² + (b/a)x = −c/a.
3. Half of b/a is b/(2a). Square it and add to both sides: x² + (b/a)x + b²/(4a²) = b²/(4a²) − c/a.
4. The left side is a perfect square: (x + b/(2a))² = (b² − 4ac) ÷ (4a²).
5. Take the square root of both sides: x + b/(2a) = ± √(b² − 4ac) ÷ (2a).
6. Subtract b/(2a): **x = [−b ± √(b² − 4ac)] ÷ (2a)**.
/EX

EQ: x = [−b ± √(b² − 4ac)] ÷ (2a)

The part under the root, **D = b² − 4ac**, is the **discriminant**. It tells you how many real solutions exist:
- D > 0: two different real solutions (the parabola crosses the x-axis twice).
- D = 0: one repeated solution (the parabola just touches the x-axis).
- D < 0: no real solutions (the parabola floats above or below the axis).

EX: Solve 2x² − 5x − 3 = 0
1. a = 2, b = −5, c = −3. D = 25 − 4(2)(−3) = 25 + 24 = 49.
2. x = [5 ± 7] ÷ 4.
3. x = 12/4 = **3** or x = −2/4 = **−1/2**. Factoring agrees: (2x + 1)(x − 3) = 0.
/EX

EX: Solve x² + 2x − 4 = 0 (does not factor nicely)
1. a = 1, b = 2, c = −4. D = 4 + 16 = 20.
2. x = [−2 ± √20] ÷ 2 = [−2 ± 2√5] ÷ 2 = **−1 ± √5**.
3. That is about 1.236 or −3.236. When factoring fails, the formula always works.
/EX

### The vertex without completing the square
The vertex of y = ax² + bx + c is at x = −b ÷ (2a), exactly halfway between the two roots. Put that x back to find y.

GRAPH: y = x² − 4x + 3 | x | y | -1,8 0,3 1,0 2,-1 3,0 4,3 5,8 | Roots at x = 1 and x = 3. Vertex at x = −b ÷ 2a = 4 ÷ 2 = 2, where y = −1. The curve is drawn with straight pieces between the plotted points.

### Quick self-check

Q: The domain of f(x) = 1/(x − 2) is…; all x; x ≠ 2; x > 2; x ≠ 0; 2; The denominator is zero when x = 2, so that input is not allowed.
Q: The discriminant of x² + 4x + 5 is…; 36; −4; 16; 0; 2; D = 16 − 20 = −4. It is negative, so there are no real solutions.
Q: The vertex of y = x² − 6x + 5 is at x =…; 3; −3; 6; 5; 1; x = −b ÷ 2a = 6 ÷ 2 = 3.

P: Find the domain of f(x) = √(2x + 6). => 2x + 6 ≥ 0, so **x ≥ −3**.
P: Find the line through (0, 4) and (2, 0). => m = −4 ÷ 2 = −2, c = 4: **y = −2x + 4**.
LVL: Level 2 | Quadratics
P: Complete the square for x² − 8x + 3 and state the vertex. => (x − 4)² − 13. Vertex **(4, −13)**.

LVL: Level 3 | Use it
P: A farmer has 40 m of fence for a rectangular pen against a wall (three sides). What width gives the largest area? => Width w, length 40 − 2w. Area A = w(40 − 2w) = −2w² + 40w. Vertex at w = −40 ÷ (2 × −2) = **10 m**. Then the length is 20 m and the maximum area is **200 m²**.
P: A company's profit is P = −2x² + 120x − 1000 (thousand taka) for x units. Find the break-even points and the production that maximises profit. => P = 0: x² − 60x + 500 = 0, so (x − 10)(x − 50) = 0, break-even at **10 and 50 units**. Maximum at x = 30, P = −1800 + 3600 − 1000 = **800 thousand taka**.
LVL: Challenge | Sum and product
P: The roots of x² − 7x + 12 = 0 are 3 and 4. Show that for any ax² + bx + c = 0 with roots r and s, r + s = −b/a and rs = c/a. Use it to write a quadratic with roots 2 + √3 and 2 − √3 without solving. => From the formula the roots are [−b + √D]/(2a) and [−b − √D]/(2a). Their sum is −2b/(2a) = **−b/a**. Their product is (b² − D)/(4a²) = 4ac/(4a²) = **c/a**. For the new quadratic: sum = 4 and product = 4 − 3 = 1, so **x² − 4x + 1 = 0**.

@section physics | 3 · Physics: free fall | 35 min

### Everything falls the same way
Drop a hammer and a feather on the Moon, where there is no air, and they hit the ground together. On Earth, air resistance hides this. If we ignore air, every falling object has the **same acceleration**, called the **acceleration due to gravity**:

EQ: g = 9.8 m/s² (downward)

So a falling object's velocity grows by 9.8 m/s every second. After 3 s from rest it is moving at about 29 m/s, roughly 106 km/h.

KEY: Free fall is just constant acceleration. Use SUVAT from Week 1 with a = g = 9.8 m/s². The only new thing is a sign choice: pick **up** as positive, then a = −9.8 m/s². Or pick **down** as positive for a drop, then a = +9.8.

BN: বাতাসের বাধা বাদ দিলে সব বস্তু একই ত্বরণে পড়ে, g = 9.8 m/s² নিচের দিকে। ফ্রি ফল মানে নতুন কোনো সূত্র নয়: Week 1 এর SUVAT সমীকরণে a = g বসালেই হলো। শুধু দিকের চিহ্ন ঠিক রাখো: উপরে ধনাত্মক ধরলে a = −9.8।

EX: Dropped from a tower
1. A stone is dropped from rest from a tower 19.6 m high. Take down as positive: u = 0, a = 9.8, s = 19.6.
2. s = ½at²: 19.6 = 4.9t², so t² = 4, **t = 2 s**.
3. v = u + at = 0 + 9.8 × 2 = **19.6 m/s**.
4. Check with v² = u² + 2as: 2 × 9.8 × 19.6 = 384.16, and 19.6² = 384.16 ✓.
/EX

### Thrown upward
EX: A ball thrown up at 20 m/s
1. Take up as positive: u = +20, a = −9.8.
2. **Top of the flight:** velocity is zero for an instant. 0 = 20 − 9.8t, so t = 2.04 s.
3. **Maximum height:** v² = u² + 2as gives 0 = 400 − 19.6s, so s = **20.4 m**.
4. **Return to the ground:** displacement is zero: 0 = 20t − 4.9t², so t(20 − 4.9t) = 0, giving t = 0 or t = **4.08 s**.
5. By symmetry the way up takes 2.04 s and the way down 2.04 s. The ball lands at **−20 m/s**, the same speed it left with, now heading downward.
/EX

GRAPH: Height of the ball | time (s) | h (m) | 0,0 0.5,8.8 1,15.1 1.5,19 2,20.4 2.5,19.4 3,15.9 3.5,10 4,1.6 4.08,0 | The height h = 20t − 4.9t² is a parabola. Its roots are t = 0 and t = 4.08 s. Its vertex, at t = −b ÷ 2a = 2.04 s, is the top of the flight at 20.4 m. Everything you learned about quadratics today is visible here.

BN: ওপরে ছোঁড়া বলের উচ্চতা h = 20t − 4.9t², এটা একটা দ্বিঘাত ফাংশন। মূল দুটো t = 0 (ছোঁড়ার মুহূর্ত) আর t = 4.08 (মাটিতে ফেরা)। ভার্টেক্স t = 2.04 এ, সর্বোচ্চ উচ্চতা ২০.৪ m। ওপরে ওঠা আর নিচে নামার সময় সমান, আর মাটিতে ফেরার সময় গতি ঠিক ছোঁড়ার গতির সমান।

TRAP: At the top of the flight the velocity is zero, but the **acceleration is still 9.8 m/s² downward**. If the acceleration were zero, the ball would hang there forever. Velocity zero does not mean acceleration zero.

### Quick self-check
QUIZ:
Q: A stone is dropped from rest. Its speed after 2 s is about…; 4.9 m/s; 9.8 m/s; 19.6 m/s; 39.2 m/s; 3; v = gt = 9.8 × 2 = 19.6 m/s.
Q: At the top of a ball's flight, its acceleration is…; zero; 9.8 m/s² upward; 9.8 m/s² downward; undefined; 3; Gravity keeps acting, so the acceleration is 9.8 m/s² downward all the time.
Q: A ball is thrown up at 15 m/s. It returns to the thrower's hand with speed…; 0; 7.5 m/s; 15 m/s; 30 m/s; 3; Symmetry: it lands at the same speed it left with, in the opposite direction.
Q: Which falls faster in a vacuum, a 1 kg stone or a 10 kg stone?; the 10 kg stone; the 1 kg stone; neither, they fall together; depends on size; 3; In a vacuum all objects have the same acceleration g.

### Practice
LVL: Level 1 | Dropping
P: A coin is dropped from a bridge and takes 3 s to hit the water. How high is the bridge, and how fast is the coin going on impact? => s = ½ × 9.8 × 9 = **44.1 m**. v = 9.8 × 3 = **29.4 m/s**.
P: How long does an object take to fall 80 m from rest? => 80 = 4.9t², so t² = 16.33 and **t = 4.04 s**.
LVL: Level 2 | Thrown upward
P: A ball is thrown up at 14.7 m/s. Find the time to the top and the maximum height. => t = 14.7 ÷ 9.8 = **1.5 s**. h = 14.7² ÷ 19.6 = **11.03 m**.
P: A stone is thrown downward at 5 m/s from a 30 m cliff. Find its speed at the bottom and the time taken. => Down positive: v² = 25 + 2(9.8)(30) = 613, so **v = 24.8 m/s**. t = (24.8 − 5) ÷ 9.8 = **2.02 s**.
LVL: Challenge | The well
P: You drop a stone into a well and hear the splash 3.0 s later. Sound travels at 340 m/s. How deep is the well? => Let the depth be d. Fall time t₁ = √(d ÷ 4.9). Sound time t₂ = d ÷ 340. Total 3 = t₁ + t₂. Try d = 40: t₁ = 2.86, t₂ = 0.118, total 2.98 s. So the well is about **40 m deep** (the exact answer is 40.7 m). Ignoring the sound's travel time would give 44.1 m, an error of 8%.

### Recap
- A function gives one output for each input. Domain = allowed inputs. Range = possible outputs.
- Line: y = mx + c. Quadratic: parabola with vertex at x = −b ÷ 2a.
- Quadratic formula x = [−b ± √(b² − 4ac)] ÷ 2a, and the discriminant D = b² − 4ac decides the number of real roots.
- Free fall: SUVAT with a = g = 9.8 m/s². Symmetry up and down.

BN: আজকের সারকথা: ফাংশন মানে এক ইনপুট এক আউটপুট। দ্বিঘাতের ভার্টেক্স x = −b/2a এ। D = b² − 4ac ঋণাত্মক হলে বাস্তব মূল নেই। ফ্রি ফল মানে a = g = 9.8, উপরে ওঠা আর নিচে নামার সময় সমান।
